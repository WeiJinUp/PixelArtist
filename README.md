# Pixel Style Blog

This is a simple, static, pixel-art themed blog website.

## Features

*   Basic HTML structure
*   Pixel-art inspired CSS styling
*   Retro color scheme
*   Uses the 'Press Start 2P' pixel font from Google Fonts

## Styling with NES.css

This blog now uses [NES.css](https://nostalgic-css.github.io/NES.css/) to achieve its retro, pixel-art appearance. NES.css is a NES-style CSS Framework that provides a range of components and styles.

## How to View

1.  Clone or download this repository.
2.  Navigate to the project directory.
3.  Open the `index.html` file in your web browser.

## Deploying to GitHub Pages

You can easily host this blog for free using GitHub Pages. Here's how:

1.  **Ensure your code is pushed to GitHub:** Make sure all your latest changes (especially `index.html` and `style.css` in the root directory) are committed and pushed to your repository on GitHub.
2.  **Go to your repository on GitHub.com.**
3.  **Navigate to Settings:** Click on the "Settings" tab (usually near the top of your repository page).
4.  **Select "Pages" in the sidebar:** In the left sidebar of the Settings page, click on "Pages" (under the "Code and automation" section).
5.  **Choose a source:**
    *   Under "Build and deployment", for "Source", select "Deploy from a branch".
    *   Under "Branch", select your main branch (commonly `main` or `master`) and ensure the folder is set to `/ (root)`.
6.  **Save changes:** Click "Save".
7.  **Wait for deployment:** GitHub Pages will then build and deploy your site. This might take a few minutes.
8.  **Access your site:** Once deployed, GitHub Pages will provide you with a URL (usually something like `https://<your-username>.github.io/<repository-name>/`). You can find this URL at the top of the GitHub Pages settings page.

Your pixel blog should now be live at that URL!
